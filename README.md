🚚 Calculadora de Frete - C# Windows Forms

Primeira versão de uma aplicação desenvolvida em *C# com Windows Forms**, criada com o objetivo de praticar conceitos de programação, interfaces gráficas e lógica de negócios.

O sistema realiza o cálculo de frete com base nas informações fornecidas pelo usuário, permitindo uma estimativa simples do custo da viagem.

⚠️ Este projeto está em desenvolvimento e receberá novas funcionalidades e melhorias nas próximas versões.

Funcionalidades

- Seleção do tipo de veículo.
- Exibição da imagem do veículo escolhido.
- Cálculo da distância percorrida.
- Opção de viagem de ida e volta.
- Cálculo da quantidade de combustível necessária.
- Cálculo do custo estimado do combustível.
- Interface gráfica desenvolvida com Windows Forms.

🛠️ Tecnologias utilizadas

- C#
- .NET Framework
- Windows Forms
- Visual Studio

🚀 Como executar

1. Clone o repositório:

bash
git clone https://github.com/TulioPinheiro/Calcular-Frete-C--Zatec

-Abra a parte e click em Calcular Frete C# Zatec.exe

Após abrir a aplicação:

1. Digite o tipo de veículo (Carro, Moto ou Caminhão).
2. Informe a distância da viagem.
3. selecione o valor que sera cobrado por km , na caixa de tabela 1,2,2,5,3,3,5 , reais por KM
4. Informe a autonomia do veículo (km/L).
5. Digite o valor do combustível.
6. Caso a viagem seja de ida e volta, marque a opção correspondente.
7. Clique no botão **OK** para realizar o cálculo.
8. O sistema exibirá:
   - Veículo selecionado;
   - Imagem do veículo;
   - Quantidade de combustível necessária;
   - Valor estimado do combustível.
